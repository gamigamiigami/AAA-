# ミニゲーム ラッシュ

ゆびさき ひとつで あそべる ミニゲームあつめ。
メイドインワリオ／リズム天国のテンポを目標にした、タッチ操作のマイクロゲーム集です。

- **縦持ちのスマホが主戦場**。タップ・フリック・ドラッグ・長押しだけで全部遊べます
- **依存ライブラリゼロ**。素の ES Modules ＋ Canvas 2D ＋ WebAudio
- **アセットファイルもゼロ**。絵は手続き描画、音はすべて実行時合成。完全オフラインで動きます

## 遊ぶ

```sh
node tools/server.mjs src 8080   # → http://127.0.0.1:8080
```

`?seed=abc` を付けると、そのシードで毎回まったく同じ展開になります（バグ再現・スクショ比較用）。

単一HTMLにまとめる場合：

```sh
node tools/bundle.mjs            # dist/index.html と dist/artifact.html を生成
```

## 中身

| 場所 | 役割 |
|---|---|
| `src/engine/` | 座標系・ビート時計・タッチ入力・固定タイムステップのループ・シード付き乱数 |
| `src/design/` | デザイントークン（配色・型スケール・イージング・レイアウト）。**数値の唯一の出どころ** |
| `src/gfx/` | 描画キット。`body()` が1色からアウトライン・押し出し・陰・グロス・接地影を導出する |
| `src/audio/` | WebAudio 合成。ステージ別の曲、効果音、生成インパルス応答のリバーブ |
| `src/game/` | セッション進行（命令カード→プレイ→判定）、画面ルーティング、セーブ |
| `src/ui/` | タイトル／ステージ選択／HUD／命令カード／リザルト／画面遷移 |
| `src/microgames/` | ミニゲーム本体。1本 = 1フォルダ |
| `tools/` | 静的サーバ・QAハーネス・単体プレビュー・バンドラ |

### 設計の要点

**時間の単位はビートで、秒ではありません。** `AudioContext.currentTime` を親時計にした
`Conductor` があり、ミニゲームの長さも演出も遷移もすべてビートで表現されます。曲はゲームを
またいで鳴り続け、難易度が上がるとテンポ自体が上がる（118 → 178 BPM）ので、演出は自動的に
追随します。

**設計空間は 1080×1920 の縦画面固定。** どの端末でもこの矩形は必ず全部見えます。背景だけは
画面いっぱい（`g.full`）まで広げてよく、横長の画面では景色が増えます。

**見た目の統一は `gfx.body()` が担保します。** 作者が選ぶのは1色だけで、陰影は全部そこから
導出されるので、別々に書かれたミニゲームが同じ製品に見えます。

## 開発

```sh
npx tsc --noEmit -p jsconfig.json   # JSDoc + checkJs で型検査
npx prettier --write "src/**/*.js"
node tools/qa.mjs                   # 実ブラウザでの検証一式
node tools/preview.mjs <id> 1 --shots 4   # ミニゲーム1本だけを実機で撮る
```

`tools/qa.mjs` は Playwright で本物のブラウザを動かし、次を機械的に確認します。

- 端末3プロファイル（iPhone縦／タブレット／デスクトップ）でのスクリーンショット
- **日本語グリフの豆腐検出**（私用領域文字の描画結果と画素比較する）
- **無操作ソーク** — 何もしなくても必ずリザルトまで到達する＝進行が詰まらない
- **勝利可能性** — 各ゲームの `debugHint()` に従って操作し、実際にクリアできる
- 60fps 維持とコンソールエラー0件

ミニゲームの書き方は [`docs/MICROGAME_GUIDE.md`](docs/MICROGAME_GUIDE.md) にあります。
