# ミニゲームまつり

<img alt="ミニゲームまつり" src="qa-shots/00-title.png" width="640">

命令語が出る → 数秒で終わる → すぐ次。
メイドインワリオ／リズム天国のテンポ感を狙った、**ミニゲーム 18 種のノンストップ ゲーム**です。

ベタ塗りの原色に太い黒フチ、制限時間は導火線つきの爆弾。
そして**ミニゲームごとに画風が違います**（ドット絵・粘土・紙工作・線画・レトロCG）。
絵柄がそろっていないこと自体を、このジャンルの様式として作り込んでいます。

ブラウザだけで動きます。**インストール不要・ビルド不要・外部依存ゼロ・完全オフライン**。
画像も音声ファイルも一切使わず、グラフィックは Canvas、サウンドは WebAudio で
すべて実行時に生成しています。

## あそぶ

`index.html` をブラウザで開くだけです。

```
git clone <this repo> && cd AAA-
xdg-open index.html      # macOS なら open index.html
```

ローカルサーバー経由で開きたい場合:

```
npx http-server . -p 8080     # → http://localhost:8080
```

### そうさ

| | キーボード | マウス / タッチ |
|---|---|---|
| うごかす | ← → ↑ ↓ / WASD | ドラッグ |
| きめる・とぶ・たたく | スペース / Enter / Z | クリック / タップ |
| ねらう | — | クリック / タップ |
| ポーズ | ESC | — |
| ミュート | M | — |

命令語が出たあとに操作ヒントのアイコンが出るので、初見でも何をすればいいかわかります。

### モード

タイトルで 2 つから選びます。

- **はじめる** — ミニゲームが次々に出てくる通しプレイ。ライフ 4 つ。
- **すきなゲーム** — 18 本を一覧から選んで 1 本だけ遊ぶ。レベル 1〜3 も選べます。
  遊び終わると一覧に戻るので、気になった 1 本を何度でも試せます（ESC でも戻れます）。

### ルール（通しプレイ）

- ライフは 4。ミニゲームを失敗すると 1 つ減り、0 でゲームオーバー。
- 4 ゲームごとに **SPEED UP**。BGM も演出もミニゲーム内の時間も、まとめて速くなります。
- 6 ゲームごとに **BOSS STAGE**（長めの 1 本勝負）。
- スコアはクリアしたミニゲームの数。ベスト記録はブラウザに保存されます。

難易度は進行に応じて 3 段階（出現数・速度・判定幅）で変化します。

### 公平さについて、決めていること

レベルが上がっても「見えない」「届かない」「詰んでいる」にはしない、と決めています。
難しさは、数が増えることと、時間が短くなることだけで作ります。

- **どの向きから来ても、反応できる時間は同じ**（ふせげ！）。画面は横に広く縦に狭いので、
  同じ速さで飛ばすと上下だけ反応時間が 3 割短くなる。距離ではなく時間を揃えています。
- **詰んでいる盤面は配らない**（にげろ！）。棒はレーンに分けて置き、レーンの境目には
  必ず体 1 つぶんの余白を残すので、棒と棒に挟まれて隙間が消えることが起きません。
  そのうえで、配る前に時間つきの迷路として検分します。最後の瞬間から時間をさかのぼって
  「ここから生き残れるか」を全部の升に書き込み、行ける升の中に生き残れない升が
  1 つでもあれば、その盤面は捨てます。どこへ逃げても、当たっていない限りまだ助かります。
  解くときの駒は本人より遅く、棒は本物より太く扱うので、判定の誤差は安全側にだけ倒れます。
  縦の棒には必ず通り穴があります（天井から床まで通った棒は、動いていても壁です）。
- **始まった瞬間に当たらない**（にげろ！）。立ち位置は盤面を作ってから決めます。
  最初の 0.7 秒、棒が太めに見ても来ない高さを探して、そこに立たせます。
- **ちがうのは 1 つ、ちがい方も 1 種類**（さがせ！）。差の大きさはレベルで薄めません。
  印で差をつけるときは全員に印を付けて、1 人だけ形を変えます（1 人だけ印がある、だと
  他の 7 人を見る必要がありません）。目の差も、閉じ目だけでなく、笑い目・片目・
  眠そう・大きい目・怒り目を使い分けます。
- **一番遅い道具で届く**。マウスのクリック 1 回しかできない人が押し切れる回数・
  跳べる高さを下限にしています（れんだ！／とべ！）。
- **「もう戻せない角度」を作らない**（ささえろ！）。棒を倒す力 sin(a)×G より、
  押し戻せる力のほうが必ず大きくなるよう、CTRL を G と限界角から決めています。
  まだ倒れていないのに手遅れ、という時間が生まれないようにするためです。
  そのうえで、負けになるのは棒が地面まで倒れきってから。限界を越えた瞬間に
  画面を止めると、まだ立って見える棒のまま終わってしまい、納得できません。
- **落ちる理由が画面に出ている**（のばせ！）。棒の上は端まで歩き、足の下に陸が
  無いところで落ちます。伸ばしすぎたら、向こう岸を通り越した先で落ちます。
- **隠すものは、隠されるものと違う色**（かぞえろ！）。レベル3 で数えるモノの前を
  横切るのは板塀です。草にしたら、背景の緑・草の緑・キャラの緑が重なって、
  手前か奥かも分からない絵になりました。
- **連打は音符の間隔で作る**（たいこ）。長押しの帯にすると、そこだけ別の遊びに
  なってしまいます。4 分が続いたあとに 8 分を 4 つ並べれば、それだけで手は連打に
  なります。判定幅は 8 分の間隔の半分より狭くして、1 回の入力がどの音符のものか
  決まらない状態を作りません。
- **まちがえたら、正解を見せる**（さがせ！）。正解のところだけ穴を空けて暗くします。
  「ちがった」とだけ言われても、どこが違ったのか分からないままだと次に生きません。
- **見えない差は使わない**（さがせ！）。ほっぺは薄い赤なので、ほっぺで差をつける回は
  赤い体を使いません。
- **終わったことは知らせない**（ふせげ！）。どこから来るかの矢印は、飛び終わっても
  消しません。消すと画面が「もう右からは来ない」と教えてしまい、残り 1 発のころには
  防ぐ前に答えが出ています。

`node tools/playtest.js` は、この「ちゃんと操作すればクリアできる」をマウス操作だけで
全レベル検証します。キーボードでしか勝てないゲームがあれば、ここで落ちます。

## つくり

設計上の取り決めは [ARCHITECTURE.md](ARCHITECTURE.md) にまとめてあります。要点だけ:

- **ベタ塗り原色 + 太い黒フチ + トゥーンシェード**（ベタ / 影の面 / ハイライトの面の 3 階調）。
- **画風はミニゲームごとに変える**。`style: 'clay'` のように 1 行宣言するだけで、
  粘土・紙工作・線画・レトロCG の質感が掛かる（`core/texture.js` が
  オフスクリーン合成の最後に一括で処理するので、ミニゲーム側は画風を意識しない）。
- **画面内に説明文を置かない**。命令語ひとつで伝わる画を作る。
- **論理解像度 960×540 固定**、レターボックスで DPR 対応。更新は固定 1/60 秒。
- **進行はすべてビート単位**。BPM を上げると演出も BGM もゲーム内時間も同時に速くなる（`speed` 一本で制御）。
- **乱数はシード付き RNG のみ**（`Math.random()` はコードベースで未使用）。同じ状況を再現できます。
- ミニゲームは 1 ファイル 1 本、互いを一切参照しません。追加は `GG.reg({...})` を呼ぶだけ。

```
src/core/       エンジン層（ゲーム内容を知らない）
src/microgames/ ミニゲーム 18 本
tools/          QA スクリプト
```

### ミニゲームを足す

`src/microgames/mygame.js` を作って `index.html` に `<script>` を 1 行足すだけです。

```js
GG.reg({
  id: 'mygame', verb: 'おせ！', verbEn: 'PUSH!',
  control: 'press', beats: 8, bg: ['#ff9f43', '#b33771'],
  create: function (c) {
    return {
      update: function (dt) { if (c.input.actHit) c.win(); },
      draw: function (g) { g.text('おして！', c.W / 2, 270, { size: 48 }); }
    };
  }
});
```

`c.rng` は必ず使ってください（`Math.random()` は禁止）。API の詳細は ARCHITECTURE.md の 2 章。
色は `GG.PAL`、地面は `GG.A.GROUND` のプリセットから選ぶと全体の世界観が揃います。
`style` を変えるだけで絵柄の系統を丸ごと差し替えられます。

## 開発・QA

Node.js と Playwright があれば、実際にブラウザで走らせて検証できます。

```
node tools/qa.js              # 全ミニゲームのプレイ画面を qa-shots/ に撮る + エラー収集
node tools/qa.js dodge 3      # 1 本だけ / 難易度 3
node tools/sheet.js           # 撮った画像を 1 枚のコンタクトシートに合成
node tools/playtest.js        # ページ内で自動プレイヤーを走らせ、全難易度でクリア可能か検証
```

`playtest.js` は「ちゃんと操作すればクリアできるか」を 60fps でブラウザ内から検証します。
実際にこれで、**カゴが物理的に間に合わない星の配置**や、
**時間内にワクへ届かないお宝**といったクリア不能バグを見つけて直しました。
